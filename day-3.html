Calling A Function


function show(pet) {
    console.log(pet.name + " comes from " + pet.origin + ".");
}
show(pets[0]);

Parameter/Object = "pet"
Argument/Value = "pets[0]"
In this example, when the function is called, the name and the origin of the cat specifically located in the 0 position of the index is given.

Adding a CTA button

A CTA button was added so that when the function is called, a description of a cat will appear in the output box


	let button = document.getElementById("describe-button");
	let output = document.getElementById("output");

	function showPet(pet) {
	output.textContent = pet.name + " comes from " + pet.origin + ".";
	}

	button.addEventListener("click", function () {
	showPet(pets[0]);
});
