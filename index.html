Send a request, read the JSON response, and explain what it means.

Step 1 — The URL is the request

I entered a call for the DOG CEO endpoint and was given the json response. I then formatted the response using pretty-json to make it readable. …

{
  "message": "https://images.dog.ceo/breeds/hound-afghan/n02088094_2062.jpg",
  "status": "success"
}
Read the DOG CEO API documentation

Reflection Day 1

Today I learned how different an API response looks when it's raw versus pretty‑printed. In raw.json, everything is squeezed into one long line, so all the properties and values blur together. But when you pretty‑print the same JSON, the object gets spaced out and indented, which makes each property readable and way easier to understand. Seeing that difference helped me understand why dot notation works — you're just picking one property out of that big object.

Keeping API Key secret

An api key must stay secret because it is like a personalized password assigned specifically to a person; having access to this code gives the user access to personal and valuable data.
