Reflection Day 1

Today I learned how different an API response looks when it's raw versus pretty‑printed. In raw.json, everything is squeezed into one long line, so all the properties and values blur together. But when you pretty‑print the same JSON, the object gets spaced out and indented, which makes each property readable and way easier to understand. Seeing that difference helped me understand why dot notation works — you're just picking one property out of that big object.
