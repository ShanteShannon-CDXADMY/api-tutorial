forEach vs Map

	
 Today I learned that both forEach and map loops through an array and runs the function on each item; forEach does not collect or save the return value and map collects the return value from each call. map builds a new array of the return value and is used when new data is created. 


// forEach: ignores return values
pets.forEach(function (pet) {
  return summarize(pet);   // thrown away
});

// map: collects return values
let lines = pets.map(function (pet) {
  return summarize(pet);   // saved in new array
});
